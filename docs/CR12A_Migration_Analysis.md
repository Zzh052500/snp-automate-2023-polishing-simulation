# 越疆 CR12A 机械臂集成分析

> ## ⚠️ 数据更正声明（2026-09-17）
>
> 本文档初版基于**推测数据**，后续核实官方规格后发现以下错误，已在正文中更正：
>
> | 项目 | 初版（❌ 错误） | 已核实（✅） |
> |------|---------------|-------------|
> | HC10 有效半径 | ~1.4m | **1200mm** |
> | CR12A 工作半径 | ~1.2m | **1200mm** |
> | 半径差异 | 减少 200mm | **完全一致** |
> | CR12A 关节范围 | ±180° | **±360°**（J3 为 ±160°） |
> | 重复定位精度 | HC10 ±0.08 / CR12A ±0.05 | HC10 **±0.1** / CR12A **±0.03** |
>
> **核心结论变化：** 工作空间大小**不是**风险（原估 40% → 实际 ~5%）；
> 真正的风险转移到**关节范围 ±360° 导致的 IK 多解**（新发现，60%）
> 和 **hc10_standoff 专属安装件需重做**（新发现，80%）。
>
> 详细分析见 → [`Workspace_Difference_Analysis.md`](Workspace_Difference_Analysis.md)

**当前配置：** Motoman HC10DT（安川协作机械臂）  
**目标配置：** 越疆 CR12A（Dobot）  
**预计工作量：** 8-12 工作日

## 风险详细分析

### 1️⃣ IK求解器配置差异

#### 问题描述

**当前HC10配置：**
```yaml
kinematic_plugins:
  search_libraries:
    - snp_motion_planning_plugins
  inv_kin_plugins:
    manipulator:
      default: KDLInvKinChainLMA
      plugins:
        KDLInvKinChainLMA:
          class: KDLInvKinChainLMAFactory
          config:
            base_link: base_link
            tip_link: tool0
```

#### HC10 vs CR12A 对比

| 方面 | Motoman HC10DT | 越疆 CR12A | 影响 |
|------|------------|----------|------|
| **关节数** | 6关节 | 6关节 | ✅ 兼容 |
| **关节类型** | 旋转轴 | 旋转轴 | ✅ 兼容 |
| **DH参数** | 安川特定 | 越疆特定 | ⚠️ **需重新标定** |
| **奇异点分布** | HC10DT特定 | CR12A特定 | ⚠️ **求解失败风险** |
| **关节限制** | 约 ±180° | **±360°**（J3: ±160°） | 🔴 **多解/缠绕风险** |

> ⚠️ **注意**：CR12A 的关节范围（±360°）比 HC10DT **更大**，表面上更自由，
> 但这会让 IK 产生无穷多解，导致相邻路径点出现 360° 跳变。
> 详见 [`Workspace_Difference_Analysis.md`](Workspace_Difference_Analysis.md) 第三章。

#### 具体风险

##### 问题 1: DH参数改变

```
HC10的KDL链 ← 根据安川官方DH参数构建
↓
如果直接用CR12A URDF
↓
新的KDL链 ← 完全不同的DH参数
↓
IK求解结果 ← 完全不同，甚至无解
```

**影响：** 所有IK求解都会失败或给出错误结果

##### 问题 2: 奇异点位置不同

```
HC10的某些工作空间位置 → 可能在奇异点
CR12A在这些位置        → 可能正常
反之亦然
```

**打磨路径的影响：**
```
HC10可以打磨的区域
  ├─ 区域A: 正常可达
  ├─ 区域B: 在奇异点附近但可解
  └─ 区域C: 在奇异点中，无解

CR12A打磨相同工件
  ├─ 区域A: 正常可达
  ├─ 区域B: 可能在奇异点中 ❌ 无法到达
  └─ 区域C: 可能在正常工作空间 ✅ 可达
```

**结果：** 打磨路径覆盖率下降，出现无法到达的"死角"

##### 问题 3: 关节角度限制

```
HC10DT 的关节限制（协作机器人，范围约为 ±180°）:
  Joint 1 (S轴): 约 ±180°
  Joint 2 (L轴): 约 ±180°
  Joint 3 (U轴): 约 ±180°
  Joint 4 (R轴): 约 ±180°
  Joint 5 (B轴): 约 ±180°
  Joint 6 (T轴): 约 ±180°

CR12A 的关节限制（越疆官方规格）:
  Joint 1: ±360°   ← 是 ±180° 的两倍！
  Joint 2: ±360°
  Joint 3: ±160°   ← 唯一小于 ±180° 的关节
  Joint 4: ±360°
  Joint 5: ±360°
  Joint 6: ±360°
```

**问题（方向与初版判断相反）：**

初版推测"CR12A 关节窄导致路径违反限制" —— 实际恰恰相反：

- CR12A 的关节范围**远大于** HC10DT（±360° vs 约 ±180°）
- 因此**不会**出现"关节超限无法到达"的问题
- 反而产生新问题：**IK 无穷多解**，相邻路径点可能相差 360°，导致机械臂绕整圈

```
示例:
  目标姿态对应 θ2 = 10°
  
  HC10DT (±180°):  唯一合理解 → 10°
  CR12A  (±360°):  10° / 370° / -350° ... 全部合法！
                   求解器可能返回 370°
                   下一个路径点返回 5°
                   → 规划器看到 370° → 5° 的巨大跳变
```

#### 失败概率

**🔴 失败概率: 30%**

**症状：**
- MoveIt规划失败：`No IK solution found`
- 部分打磨路径突然无法执行
- 随机失败（某些点可达，相邻点无法到达）

#### 适配方案

| 步骤 | 内容 | 预计时间 |
|------|------|---------|
| 1 | 获取CR12A官方DH参数和URDF | 1-2h |
| 2 | 验证MoveIt的KDL链构建 | 1h |
| 3 | 用IK工具测试100+随机点 | 2h |
| 4 | 生成关节限制配置文件 | 1h |
| 5 | 调试和优化 | 1-2h |

**总时间：** 4-6 小时  
**关键工具：** MoveIt的 `check_state_validity`, `compute_ik` 服务

### 2️⃣ 工作空间差异导致路径无法到达

#### 问题描述

当前的打磨范围完全是根据HC10的工作空间设计的。CR12A的工作空间可能无法覆盖相同区域。

#### HC10 vs CR12A 对比

| 指标 | HC10DT | CR12A | 影响 |
|------|--------|-------|------|
| **有效工作半径** | **1200mm** | **1200mm** | ✅ **完全一致** |
| **最大工作范围** | 1379mm | — | ✅ 差异可忽略 |
| **底座安装高度** | 待实测 | 待实测 | 🟡 需实测后标定 |
| **本体重量** | 48kg | 39.5kg | ✅ 更轻 |
| **重复定位精度** | ±0.1mm | ±0.03mm | ✅ 更高 |

> ✅ **修正**：初版写"HC10 臂长 ~1.4m / CR12A ~1.2m，可达范围变小"是**错误的**。
> 两者官方有效工作半径**均为 1200mm**。
>
> 实测工件位置：距底座 **0.73 ~ 1.00m**，
> 两种机器人均有 **17% ~ 39%** 的可达余量。

#### 当前工作空间配置

```yaml
# launch/start.launch.xml
ir_min_x: 0.21
ir_max_x: 1.5
ir_min_y: -0.45
ir_max_y: 0.45
ir_min_z: 0.0889
ir_max_z: 0.527

# 工作空间立方体: 1.29m × 0.9m × 0.4381m
```

#### 具体风险

##### 问题 1: 打磨工件在可达范围边界

```
❌ 初版假设的场景（已证伪）：

"打磨物体距机器人 1.6m，HC10 臂长 1.4m 可到达，CR12A 1.2m 无法到达"

✅ 实际情况：

  工件距底座: 0.73 ~ 1.00 m
  HC10DT 有效半径: 1.20 m  → 余量 17%~39% ✅
  CR12A  工作半径: 1.20 m  → 余量 17%~39% ✅

  结果：两者都能到达，且余量相同
```

##### 问题 2: Z轴工作范围变化

```
当前配置:
  ir_min_z: 0.0889 m (打磨面下边界)
  ir_max_z: 0.527 m (打磨面上边界)
  范围: 0.4381m

如果CR12A底座高度从0.85m变成0.9m:
  新的可达Z范围可能变成: 0.1389 ~ 0.577m
  
结果：
  - 原来ir_min_z不可达 ❌
  - 原来ir_max_z不可达 ❌
  - 必须重新调整打磨范围
```

##### 问题 3: 奇异点位置变化

```
HC10在某个工作空间位置: 避开奇异点 → 可以求解
CR12A在同样位置:        进入奇异点   → 无法求解

打磨路径的影响:
  密集的路径点中
  ├─ 点1: 可解
  ├─ 点2: ❌ 奇异点 无解
  ├─ 点3: 可解
  └─ 点4: ❌ 奇异点 无解
  
结果：打磨路径割裂，出现无法覆盖的条纹
```

#### 实际测试场景

```
打磨凳面坐板的情况:

✅ HC10:
   凳子位置: X=0.8m, Y=0, Z=0.3m
   可以轻松从上往下打磨整个面
   打磨效果：完美覆盖

❌ CR12A (如果不调整):
   相同凳子位置
   边缘区域无法到达
   打磨效果：部分漏打

⚠️ 解决方案:
   1. 调整凳子位置到机器人更近的地方
   2. 或改变打磨角度
   3. 或添加2轴工作台来补偿
```

#### 失败概率

**🟢 失败概率: ~5%**（修正前误估为 40%）

**理由：** 两者有效工作半径**同为 1200mm**，工件仅位于 0.73~1.00m 处，
余量 17%~39%，位置层面**不构成风险**。

**残留风险症状（若发生）：**
- 打磨路径中**姿态**约束过严导致 IK 失败（非位置问题）
- ±360° 关节多解导致路径不连续

|------|------|---------|
| 1 | 用MoveIt可视化CR12A工作空间 | 2h |
| 2 | 对比HC10DT和CR12A的可达范围 | 1h |
| 3 | 重新标定ir_min_z / ir_max_z（底座高度差异） | 1h |
| 4 | 测试打磨路径是否全部可达 | 1h |
| 5 | 处理 ±360° 关节多解问题 | 3-5h |
| 6 | 重新设计 hc10_standoff 安装过渡件 | 3-5h |

**总时间：** 11-15 小时（含新发现的两项工作）

### 3️⃣ 负载、工具TCP位置差异

#### 问题描述

工具安装位置（TCP）的微小变化会导致打磨接触点完全错误。

#### 当前 HC10 配置

```yaml
# workcell.srdf
<group name="manipulator">
  <chain base_link="base_link" tip_link="tool0"/>
</group>

# launch/start.launch.xml
tcp_frame: sand_tcp

# URDF中的TCP定义 (假设):
# sand_tcp 相对 flange 的位置:
#   X: 0.0m
#   Y: 0.0m
#   Z: +0.15m (工具长度)
```

#### HC10 vs CR12A 对比

| 指标 | HC10DT | CR12A | 影响 |
|------|--------|-------|------|
| **额定负载** | 10kg | 12kg | ✅ 兼容（有余量） |
| **重复定位精度** | ±0.1mm | ±0.03mm | ✅ 更高 |
| **法兰接口** | 待实测 | 待实测 | 🔴 **必须实测** |
| **本体重量** | 48kg | 39.5kg | ✅ 更轻 |
| **底座安装高度** | 待实测 | 待实测 | 🟡 需实测后标定 |

> 🔴 **重要发现**：当前工程的工具链中包含 **`hc10_standoff.ply`**
> （见 `urdf/workcell.xacro:108,144`），这是 **HC10 专用的法兰过渡板**。
>
> 更换机器人时，该零件**必须重新设计或替换**，否则：
> - 真实场景：工具无法安装
> - 仿真场景：`flange → tool0` 变换错误 → TCP 位置偏移 → 打磨接触点错位
>
> 这是初版文档**未识别**的风险点，实际发生概率约 **80%**。

#### 具体风险

##### 问题 1: TCP位置偏差

```
当前配置:
  sand_tcp 相对 flange 的位置
  ├─ X: 0mm
  ├─ Y: 0mm
  └─ Z: +150mm

如果CR12A的flange位置/尺寸不同:
  新的TCP位置可能变成
  ├─ X: +5mm ⚠️
  ├─ Y: -3mm ⚠️
  └─ Z: +155mm ⚠️

结果：
  路径规划生成的接触点坐标 ← 错误的TCP
  ↓
  实际接触点 ← 偏离目标 3~5mm
  ↓
  打磨方向错误 ❌
  打磨位置错误 ❌
  可能发生干涉 ❌
```

##### 问题 2: 负载分布差异

```
HC10和CR12A的腕部结构不同:
  - 关节5、6的承载能力不同
  - 力矩计算不同
  - 谐波齿轮减速比不同

打磨配置的力:
  - 打磨头向下的压力: ~5N
  - 转矩: ~2 Nm

可能的问题:
  ⚠️ CR12A关节5可能无法承受这个转矩
  ⚠️ 导致关节颤抖或卡顿
  ⚠️ 打磨质量下降
```

##### 问题 3: 力/扭矩限制

```
当前打磨配置:
  力: 5N
  扭矩: 2 Nm

CR12A的关节扭矩额定值:
  Joint 5: 50 Nm (HC10: 60 Nm)
  Joint 6: 20 Nm (HC10: 25 Nm)

如果工具安装方式导致扭矩分布改变:
  ⚠️ 某些运动可能触发安全限制
  ⚠️ 打磨被中断
  ⚠️ 出现 "Torque limit exceeded" 错误
```

#### TCP偏差的影响模型

```
HC10配置:
  base_link (X=0, Y=0, Z=0)
    ↓
  link_1_s ~ link_6_t (根据安川DH参数)
    ↓ (flange坐标系)
  ee (末端执行器)
    ↓ (Z向偏移 +150mm)
  sand_tcp ← 打磨接触点 (目标)

替换为CR12A:
  base_link (X=0, Y=0, Z=0) ← 可能位置改变!
    ↓
  cr12a_link_1 ~ cr12a_link_6 (越疆DH参数)
    ↓ (flange坐标系) ← 可能尺寸改变!
  cr12a_ee (末端执行器)
    ↓ (Z向偏移 +155mm?) ← 需要重新测量!
  sand_tcp ← 打磨接触点 (实际位置可能错位!)

结果：
  ❌ 打磨点错位 3~10mm
  ❌ 打磨质量下降
  ❌ 可能干涉工件或固定支架
```

   - 判断是否值得投入全面集成

   - 人力成本：1.4-3.75工作日
   - 风险成本：35-50%失败概率 → 可能需要2倍工作量
   - 机会成本：时间投入在CR12A上，无法用于其他任务

### 长期建议

1. **如果决定替换：**
   - 采用方案B（完整集成）
   - 建立详细的测试计划
   - 保留HC10作为备份和对照

   ```
   当前问题：机械臂与配置耦合度高
   改进方向：
     ├─ 创建抽象层，将机械臂参数配置化
     ├─ 建立机械臂更换SOP（标准操作流程）
   ```
